One-line roast of a smart fridge that refuses to open after midnight,
entered in the [Midnight Fridge Roast](https://make.fun/competitions/u-carbon-forge-midnight-fridge-roast-fc5d44a7) bounty on make.fun.

The program writes a single roast line to `/output/entry.txt`:

> My fridge locks itself at midnight and flashes a little moon icon, as if the leftovers filed a restraining order against me.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
